# A股晚报任务执行指南

> 本文档为晚报定时任务的详细执行手册，由AI代理在任务启动时读取并严格执行。

## 任务目标
生成今日A股晚报（含波浪理论多周期分析 + 晨报复盘），更新月度/年度总结（含波浪分析总结），保存到本地并提交git推送到GitHub，同步到飞书知识库（按年/月/日层级归档），最后发送飞书消息通知。

## 工作目录
`/workspace`

## 飞书配置
从 `config/feishu_config.env` 读取以下配置：
- 首页节点 token：`FEISHU_HOME_NODE_TOKEN`
- 历史报告节点 token：`FEISHU_HISTORY_NODE_TOKEN`
- 知识库 space_id：`FEISHU_SPACE_ID`
- 用户 open_id：`FEISHU_USER_OPEN_ID`
- 知识库首页链接：`FEISHU_HOME_URL`

## 日期变量
- `DATE` = YYYYMMDD（今日，如 20260911）
- `DATE_CN` = YYYY年MM月DD日（今日，如 2026年09月11日）
- `MONTH` = YYYYMM（当月，如 202609）
- `MONTH_CN` = YYYY年M月（当月，如 2026年9月）
- `YEAR` = YYYY（当年，如 2026）
- `YEAR_CN` = YYYY年（当年，如 2026年）

## 步骤1：前置检查

1. 获取当前北京时间，设置上述日期变量
2. 判断今日是否为交易日（周一至周五，节假日跳过）
3. 读取飞书配置文件：
   ```bash
   source /workspace/config/feishu_config.env
   ```
4. 创建目录（如不存在）：
   ```bash
   mkdir -p /workspace/report/$DATE
   mkdir -p /workspace/report/monthly
   mkdir -p /workspace/report/yearly
   mkdir -p /workspace/report/history
   ```

---

## 步骤2：读取文件

1. 读取 `/workspace/prompt/evening_report_prompt.txt` —— 晚报内容格式模板
2. 读取今日晨报：`/workspace/report/$DATE/morning_report_$DATE.md`，提取"今日核心判断"全部内容
3. 读取 `/workspace/rules.md` —— 了解现有规则库（含波浪分析规则）
4. 读取现有月度总结（如果文件存在）：`/workspace/report/monthly/${MONTH}_monthly_report.md`
5. 读取现有年度总结（如果文件存在）：`/workspace/report/yearly/${YEAR}_yearly_report.md`

## 步骤3：收集市场信息（WebSearch）

| 类别 | 具体内容 |
|-----|---------|
| 主要指数 | 上证指数、深证成指、创业板指、科创50（涨跌幅、收盘点位、最高/最低点） |
| 成交数据 | 两市成交额、北向资金全天净流入/流出金额、主力资金流向 |
| 市场情绪 | 涨跌家数比、涨停板数、跌停板数、市场宽度指标 |
| 板块表现 | 领涨/领跌板块及涨跌幅、热点驱动因素、板块资金流向 |
| 个股异动 | 涨停板复盘、连板股情况、强势股回调 |
| 国内政策 | 今日发布的经济数据、监管政策、行业政策变化 |
| 公司公告 | 重大资产重组、业绩预告、股权变动等 |
| 海外市场 | 美股盘前/日内表现、欧洲主要市场 |
| 大宗商品 | 原油、黄金今日表现 |
| 汇率 | 人民币汇率今日走势（离岸/在岸） |
| 盘后公告 | 重大事项、业绩快报、股东增减持 |
| 次日关注 | 重要数据发布、新股申购、限售股解禁 |
| 波浪分析数据 | 上证指数月K线、周K线、日K线、60分钟K线、30分钟K线的走势数据（高低点、成交量、关键技术指标如MACD、KDJ） |

## 步骤4：生成晚报

严格按照 `evening_report_prompt.txt` 格式生成，确保以下章节完整：

### 4.1 市场回顾
- 主要指数表现（表格展示）
- 成交量能（两市成交额、北向资金、主力资金）
- 市场情绪（涨跌家数、涨停跌停、市场宽度）

### 4.2 热点板块与异动分析
- 当日领涨板块及驱动因素
- 当日领跌板块及原因分析
- 个股异动复盘

### 4.3 关键数据与事件回顾
- 国内重要经济数据
- 政策消息
- 公司重要公告

### 4.4 海外市场联动
- 美股三大指数
- 欧洲、亚太主要市场
- 大宗商品（原油、黄金、铜）

### 4.5 汇率与利率
- 人民币汇率
- 国内利率市场
- 央行公开市场操作

### 4.6 收盘后重要信息
- 盘后公告
- 夜盘走势
- 次日关注

### 4.7 波浪理论多周期分析（重点章节）

**月K线波浪分析：**
- 当前波浪位置（如：第3浪第3子浪中 / 第2浪调整中 / B浪反弹中）
- 浪型结构描述（各子浪起止点、涨跌幅）
- 关键目标位（根据黄金分割率测算）
- 验证条件（确认当前浪型的技术条件）

**周K线波浪分析：**
- 当前波浪位置
- 浪型结构描述
- 关键目标位
- 验证条件

**日K线波浪分析：**
- 当前波浪位置
- 浪型结构描述
- 关键目标位
- 验证条件

**60分钟K线波浪分析：**
- 当前波浪位置
- 浪型结构描述
- 关键目标位
- 验证条件

**30分钟K线波浪分析：**
- 当前波浪位置
- 浪型结构描述
- 关键目标位
- 验证条件

**波浪图（Mermaid绘制，必须包含）：**
- 日K线波浪结构图
- 60分钟波浪结构图

**波浪理论综合判断：**
- 多周期共振状态（各周期方向是否一致，是否存在背离）
- 当前操作级别（建议的操作周期，如日线级别/60分钟级别）
- 后续演变路径（最可能的走势路径及备选路径）
- 关键拐点信号（判断浪型转换的关键信号）
- 风险提示（波浪理论的局限性及失效条件）

## 步骤8：同步到飞书知识库

### 8.1 处理当日日期节点

1. 列出首页子节点（使用配置中的 space_id 和首页 node token）：
   ```bash
   lark-cli wiki +node-list --space-id $FEISHU_SPACE_ID --parent-node-token $FEISHU_HOME_NODE_TOKEN --page-all --as user --format json
   ```
2. 查找 `title == "$DATE_CN 交易信息动态"` 的日期节点
3. 存在则复用，不存在则创建（创建到首页下）

### 8.2 处理晚报子节点

1. 列出日期父节点的子节点
2. 查找 `title == "A股晚报"` 的子节点
3. 存在则复用，不存在则创建
4. 写入晚报内容（overwrite）：
   ```bash
   lark-cli docs +update --doc <晚报obj_token> --command overwrite --doc-format markdown --content "@/workspace/report/$DATE/evening_report_$DATE.md" --as user --format json
   ```

### 8.3 更新日期父节点内容（overwrite）

将完整日期页内容（晨报精华 + 晚报精华 + 波浪分析要点 + 复盘总结）写入临时文件 `/workspace/_day_full.md`，然后：
```bash
lark-cli docs +update --doc <日期父obj_token> --command overwrite --doc-format markdown --content "@./_day_full.md" --as user --format json
rm -f /workspace/_day_full.md
```

日期页内容结构：
```markdown
# $DATE_CN 交易信息动态

## 一、晨报精华
### 核心判断
### 板块预判
### 策略建议
### 风险提示
### 波浪分析参考

## 二、晚报精华
### 市场表现
### 热点板块
### 波浪分析结论
### 资金面

## 三、今日复盘与经验总结
### 准确率评估
### 偏差与教训
### 新规则发现
```

### 8.4 处理年度节点（历史报告 → 年节点）

1. 列出历史报告子节点
2. 查找 `title == "$YEAR_CN"` 的年节点
3. 存在则复用，不存在则创建（创建到历史报告下）

### 8.5 处理月度节点（历史报告 → 年节点 → 月节点）

1. 列出年节点的子节点
2. 查找 `title == "$MONTH_CN"` 的月节点
3. 存在则复用，不存在则创建（创建到年节点下）

### 8.6 更新月度节点内容（overwrite）
```bash
lark-cli docs +update --doc <month_obj_token> --command overwrite --doc-format markdown --content "@/workspace/report/monthly/${MONTH}_monthly_report.md" --as user --format json
```

### 8.7 更新年度节点内容（overwrite）
```bash
lark-cli docs +update --doc <year_obj_token> --command overwrite --doc-format markdown --content "@/workspace/report/yearly/${YEAR}_yearly_report.md" --as user --format json
```

## 步骤9：归档清理（首页只保留最近7个交易日）

1. 重新列出首页所有子节点
2. 筛选出日期节点（title 匹配"YYYY年MM月DD日 交易信息动态"格式），排除"历史报告"
3. 按日期从新到旧排序
4. 如果日期节点数量 > 7：
   - 超出部分（最旧的那些）逐个归档
   - 对每个要归档的节点：
     1. 从标题提取年份和月份
     2. 确保历史报告下有对应年节点和月节点（不存在则创建）
     3. 移动日期节点到对应月节点下：
        ```bash
        lark-cli wiki +move --node-token <旧日期node_token> --target-parent-token <对应月node_token> --as user --format json
        ```
     4. 同时本地归档：
        ```bash
        mkdir -p /workspace/report/history/$Y/$M
        mv /workspace/report/$OLD_DATE /workspace/report/history/$Y/$M/
        ```
